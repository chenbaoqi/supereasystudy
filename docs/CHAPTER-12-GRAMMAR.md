# CHAPTER-12-GRAMMAR

Version: 1.0 Status: Approved Priority: P0 Phase: Phase 2（内容线）

> 2026-07-20 Owner 审核通过（Q1-Q5 全部按推荐）：
> 语法点以 Knowledge 双形态承载（单集合 + type 判别 + explanation 字段），
> 复用现有学习/复习/收藏链路，V1 不做语法专项测试。

## 1. Goal

点亮「语法」学习路径：上线首批小学+初中核心语法点，
让语法内容进入 学习 → 复习 → 收藏 闭环（与单词同链路）。

## 2. Scope

包含：

- Knowledge 双形态（type: 'word' | 'grammar' + explanation 字段）
- 语法层级数据（语法路径 → 语法专题包 → 专题章节 → 语法点）
- 语法点学习页（复用知识卡，展示讲解区块）
- 首批 24 个语法点内容（小学 12 + 初中 12，AI 骨架待校对）

不包含：

- 语法专项测试题（题干+选项+答案的题目级数据，V2 立项）
- 拼写/填空类输出训练

## 3. Data Model（Q1 确认）

Knowledge 单集合双形态（Everything is Knowledge，不建独立系统）：

| 字段                               | type=word（单词）                    | type=grammar（语法点）            |
| ---------------------------------- | ------------------------------------ | --------------------------------- |
| type                               | 'word'（**缺省**，历史数据无此字段） | 'grammar'                         |
| word                               | 单词                                 | 语法点名称（如「一般现在时」）    |
| meaning                            | 中文释义                             | 一句话简述                        |
| explanation                        | —                                    | **详细讲解（结构公式+用法说明）** |
| example                            | 例句                                 | 经典例句                          |
| translation                        | 例句翻译                             | 例句翻译                          |
| ipa / pronunciation / partOfSpeech | 有                                   | 无（留空即隐藏，§12.3）           |

字段只增不改（RULES §7 合规；依据：本章）。

## 4. Hierarchy（Q2 确认，零结构变更）

```
英语 → 语法（learning_path，开放）
  ├── 小学语法专题（textbook）→ 全册（semester）
  │     ├── 时态专题（chapter）→ 4 语法点
  │     ├── 词法专题 → 4
  │     └── 句型专题 → 4
  └── 初中语法专题 → 全册
        ├── 时态专题 → 4
        ├── 词法专题 → 4
        └── 句型专题 → 4
```

## 5. Learning Form（Q3 确认）

语法点学习页复用 study-detail 知识卡：

- 名称（word）+ 简述（meaning）
- **讲解区块（explanation 存在时显示）**
- 例句 + 翻译 + 发音按钮（TTS 对语法例句同样可用）
- 翻页 / 收藏 / 进度 / 完成学习 —— 全部复用，零页面新增

复习 / 收藏 / 统计 / 游戏（语法点可参与全游戏链路）自动生效。

## 6. Content（Q5 确认）

24 个语法点（AI 骨架待校对，同词汇流程）：

- 小学语法专题：时态（一般现在时/现在进行时/一般过去时/一般将来时）、
  词法（名词复数/be 动词/形容词性物主代词/情态动词 can）、
  句型（特殊疑问句/一般疑问句/祈使句/there be 句型）
- 初中语法专题：时态（过去进行时/现在完成时/过去完成时/被动语态）、
  词法（比较级与最高级/动词不定式/动名词/情态动词表推测）、
  句型（宾语从句/定语从句/状语从句/if 条件句）

## 7. Test Form（Q4 确认：V1 后置）

V1：语法学习 + 复习（review 认识/不认识）+ 收藏。
语法专项测试题（题干+选项+答案的题目级数据）与游戏适配，V2 单独立项。

> 修订（2026-07-30，Owner）：语法**不需要朗读与游戏**——游戏/朗读只针对记单词。
> 落地：学习详情对 type='grammar' 隐藏发音按钮；selectPool（全部游戏）与
> testService（单元测试）统一过滤为 type='word'（缺省按 word 处理）。
> 复习与收藏对语法点保留（语法学习闭环需要）。

## 8. Acceptance

1. 学习路径页「语法」可进入（不再 Coming Soon）
2. 出现 2 个语法专题包 → 各 3 个专题章节 → 各 4 个语法点
3. 语法点学习卡显示 名称/简述/讲解/例句/翻译
4. 可收藏、可完成学习、进度保存
5. 复习队列可包含语法点
6. 单词链路全功能回归无影响

## 9. Principle

Everything is Knowledge。语法只是 Knowledge 的一种 type，
不是新系统。复用永远大于新建。
