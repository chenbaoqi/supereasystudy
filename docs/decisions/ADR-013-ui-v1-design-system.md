# ADR-013：UI v1 设计体系（清爽蓝 + 设计令牌 + 通用组件）

- 状态：已采纳并实施（2026-09-13）
- 决策人：Owner（配色方向「清爽蓝」、范围「先 4 个 tab 页」、tabBar 图标「本地生成」三项均由 Owner 当场选定）
- 影响范围：`miniprogram/app.wxss`、新增 `miniprogram/styles/*`、`pages/{home,study,practice,mine}`、
  `pages/shared/chapter-items.wxml`、`miniprogram/app.json`、`miniprogram/config/subjects.ts`、
  `miniprogram/services/chapterService.ts`、`docs/SuperEasy-Learning-Specification.md` §12

---

## 1. 背景：界面难看的真实根因

Owner 2026-09-13 反馈「这个界面太难看了」。排查后确认根因**不是**「UI 规范没写」——
`Specification` 第 12 章于 2026-07-19 已补写并冻结。真正的原因是：

| #   | 事实                                                                                              | 后果                                                     |
| --- | ------------------------------------------------------------------------------------------------- | -------------------------------------------------------- |
| 1   | §12.1 冻结的是「UI 从简优先：V1 采用简洁列表风格，正式视觉体系后续版本细化」                      | 规范本身只冻结了一个**占位级下限**，没有可执行的视觉体系 |
| 2   | 第 12 章全篇没有把令牌落成代码：`app.wxss` 只有 17 行（仅 `page` 底色 + 占位页样式）              | 没有任何全局设计词汇存在                                 |
| 3   | 事实上唯一的设计词汇是 `pages/shared/list.wxss` 的 59 行                                          | 白卡片 + `#f6f7f9` 底 + 清一色 `#999` 文字               |
| 4   | 7 个页面的 `.wxss` 只有 1 行                                                                      | 样式无处沉淀，页面之间靠复制粘贴                         |
| 5   | §12.2 主色定的是微信绿 `#07c160`，但页面里出现了 `#1d9e75 / #534ab7 / #2b6fd6 / #d97706` 等自造色 | 一屏之内五种色系                                         |
| 6   | 三态（未开始/学习中/已完成）全用 `#999`，且文案是英文 `Not Started / Learning / Completed`        | 看不出进度，且违反 §12.1「界面文案一律中文」             |
| 7   | `app.json` 的 tabBar 只有文字、没有 `iconPath`                                                    | 底部栏是全小程序最"未完成"的一块                         |

**附带纠正**：`app.wxss` 里长期写着「UI 规范以 Specification 第 12 章为准（**该章节待补写**）」，
这条注释是过期的——第 12 章早在 2026-07-19 就写好了。本次一并修正，避免后来人继续被误导。

## 2. 决策

### 2.1 建立可执行的令牌层与组件层（新增文件，纯增量）

| 文件                                 | 职责                                                                                            |
| ------------------------------------ | ----------------------------------------------------------------------------------------------- |
| `miniprogram/styles/tokens.wxss`     | 唯一色值来源：品牌色阶 / 中性色 / 语义色 / 三态色 / 学科色 / 字号 / 间距 / 圆角 / 阴影 / 主渐变 |
| `miniprogram/styles/components.wxss` | 通用组件：卡片、列表行、箭头、chip、按钮、空状态、统计块、章节标题、Banner、英雄区              |
| `miniprogram/app.wxss`               | 只做 `@import` + `page` 基础样式，不再沉淀业务组件样式（沿用原约束）                            |

**WXSS 没有预处理器**，令牌只能靠 `page { --xxx }` 上的 CSS 自定义属性向下继承，组件内用 `var(--xxx)` 消费。

**命名前缀 `u-`**：仓库里 `pages/shared/card.wxss`、`statistics.wxss` 已占用 `.card` / `.grid`，
`pages/shared/list.wxss` 占用 `.list-item` / `.tag` / `.status`。加前缀后新旧共存，
改 4 个 tab 页不会波及其它页面。

### 2.2 配色：清爽蓝取代微信绿

| 令牌        | v1（2026-07-19 冻结） | v2（本次）                                             |
| ----------- | --------------------- | ------------------------------------------------------ |
| 主色        | `#07c160`             | `#2f6bff`（`--brand-500`）                             |
| 页面背景    | `#f6f7f9`             | `#f4f6fa`（`--bg-page`）                               |
| 圆角        | `16rpx`               | 三级 `12 / 20 / 28rpx`                                 |
| 辅助文本    | `#999999` 一色到底    | `--ink-2 #5a6478`（副文本）/ `--ink-3 #98a1b3`（辅助） |
| 导航栏      | 白底黑字              | `#2f6bff` 白字（与 tab 页头部连成一片，无接缝）        |
| tabBar 选中 | `#07c160`             | `#2f6bff`                                              |

主渐变刻意用 `180deg`（自下而上收深）而不是 `135deg`：顶边颜色与导航栏完全一致，避免出现横向接缝。

### 2.3 三态改中文 + 彩色

`Not Started / Learning / Completed` → `未开始 / 学习中 / 已完成`，并按状态着色
（灰 / 蓝 / 绿）。配色类由 `chapterService.statusClassOf()` 统一给出，
避免每个页面各写一套 `if`。

### 2.4 tabBar 图标本地生成

`scripts/gen_tabbar_icons.py`（PIL，零外部素材）生成 8 张 81×81 透明 PNG 到
`miniprogram/assets/tabbar/`：房子 / 摊开的书 / 闪电 / 人像 × 选中+未选中。
不用在线图标库：不可控，且小程序 tabBar 只认本地文件。

## 3. 严格遵守的部分（未越界）

本轮**保留**了 v1 冻结稿的两条硬约束，即便重设计也照旧：

1. **§12.1「纵向列表布局」** —— 首页学科入口不做宫格，仍是纵向列表（只把行样式升级为
   图标 + 标题 + 副标题 + chip + 箭头）。九宫格是 2026-07-19 被 Owner 明确替代掉的方案。
2. **§12.5 首页区块顺序** —— Banner → 学习统计条 → 最近学习 → 学科入口，自上而下未变。
   本次只是把「学习统计条」做成了蓝色渐变卡（含问候语与主按钮），位置与信息项不变。

另有两处**沿用但需登记**的偏离：

- §12.3 规定无数据态文案为「暂无数据」；tab 页在**特定**无数据场景给了更具体的一句话
  （如「当前年级还没有可学的单元，换个册次试试」），失败态仍严格用「加载失败，请检查网络」+「重试」。
  理由：笼统的「暂无数据」无法告诉用户下一步该干什么。如需严格一致，改回一行即可。
- 章节页（`pages/chapter/chapter`）与学习/练习页**共用同一个章节模板**，
  因此章节页的行样式会一并变为新样式。这是 DRY 设计的必然结果，非越界改动。

## 4. 后果

**正面**：色值/字号/间距/圆角第一次有了单一来源；新增页面只需组合 `u-*` 类；
状态可辨识；tabBar 补齐图标；导航栏与页面头部连成一体。

**代价 / 待办**：

- 其它页面（学科 / 教材 / 册次 / 学习详情 / 测试 / 复习 / 收藏 / 游戏 / 设置等）
  仍是旧样式，与本轮 4 页**视觉不一致**，需下一批统一。
- `pages/shared/list.wxss` 目前是新旧两套并存（旧页面还在用），等旧页面全部迁移后删除。
- 数学可视化组件（B-7）尚未开工，接入时应直接使用本套令牌。

## 5. v1.1 调色修订（2026-09-13 同日，Owner 反馈「配色再淡一点，不伤眼睛最好」）

v1 的深蓝大面积色块（导航栏 #2f6bff + 头部 #2f6bff→#1f52d6 渐变）在真机上看偏重。
v1.1 只调色与阴影，**不动任何布局与信息结构**：

| 项                 | v1                                | v1.1                                    | 理由                                          |
| ------------------ | --------------------------------- | --------------------------------------- | --------------------------------------------- |
| 导航栏             | `#2f6bff` 白字                    | 白底黑字                                | 常驻元素，深色底长时间看最累眼                |
| 页面头部           | 深蓝渐变 + 白色文字               | 极淡蓝渐变 `#eaf2fe→#dde9fb` + 深色文字 | 大面积色块改为浅底，靠阴影分层而非色差硬撞    |
| 主色（视觉）       | `#2f6bff`                         | `#5a85e0`                               | 降饱和，图标与 chip 文字用                    |
| 主色（承载白字）   | `#2f6bff`                         | `#3f6bc4`                               | 实心按钮/强调数字才用深档，白字对比度约 4.8:1 |
| 正文字色           | `#1b2333`                         | `#2a3444`                               | 比近黑柔和，长文阅读不刺眼                    |
| 成功 / 警示 / 危险 | `#16a34a` / `#f59e0b` / `#ef4444` | `#2fa06b` / `#d99a3c` / `#dd655d`       | 语义色统一降饱和                              |
| 阴影               | `0 4rpx 20rpx rgba(…,0.06)`       | `0 2rpx 12rpx rgba(…,0.05)`             | 去掉「浮起来」的塑料感                        |
| tabBar 图标        | 选中 `#2f6bff`                    | 选中 `#3f6bc4`（脚本重新生成）          | 跟主色档位一致                                |

新增 `--grad-hero`（淡蓝头部渐变）与保留 `--grad-brand`（主按钮实色渐变）两个令牌：
**头部一律用 `--grad-hero`，只有需要白字对比度的按钮/强调块才用 `--grad-brand`。**

> 「淡」的边界（避免走到另一个极端）：淡化的是**大面积**底色，
> 需要被读取的文字/数字/按钮对比度反而**提高**了一档（`--brand-600`/`--brand-700`）。
> 淡色不等于低对比——低对比才是真的伤眼。

## 5.1 迁移收口（2026-09-14，第三批）

全站 28 页分三批迁移完成，**没有遗留旧样式页面**。第三批同时做了三件结构性收口：

| 收口项                                        | 内容                                                                                                  |
| --------------------------------------------- | ----------------------------------------------------------------------------------------------------- |
| 新增 `styles/game.wxss`（`g-`）               | 5 个答题类小游戏原先各写一份 `.hud` / `.timer-bar` / `.options`，内容几乎相同，改一次要动五个文件     |
| `components.wxss` 补 `u-option` / `u-speaker` | 测试页与 4 个小游戏共用同一套选项与发音喇叭；对错反馈统一为「淡底 + 描边 + 深色字」                   |
| 新增 `--game-*` 令牌（深色街机）              | 小蜜蜂（space-shooter）与键盘组件**有意保留深色**：中文方块在深底上才看得清。色值入令牌，页面不硬编码 |

两条由此确立的规则：

1. **全站 wxss 不得出现硬编码色值**，唯一例外也必须落成令牌（如 `--game-*`）。
2. **重复三次以上的页面样式进 `styles/`**，用前缀隔离（`u-` 通用 / `g-` 游戏），页面 wxss 只留真正独有的部分。
