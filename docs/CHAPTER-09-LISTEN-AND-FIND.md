## 1. Goal

实现 SuperEasy Learning 第三款学习游戏：听音找词。

目标：训练「音 → 词」的听力辨识能力（听力是语言学习的基础通道），
与消消乐（形义配对）、极速选择（熟练速度）形成能力互补。

## 2. Scope

包含：

- Listen and Find 听音找词模式
- 播放发音 → 从 4 个英文单词中选出听到的词
- 游戏结果、掌握/薄弱分析、复习集成

不包含：

- 句子级听力、听写、语音评测、排行榜
- 预录制音频资产的批量生产（V1 用实时合成，见 §16 Q1）

## 3. Entry Flow

游戏中心 → 听音找词 → 开始游戏 → 游戏结束 → 结果页面 → 加入复习

## 4. Game Mode V1

Listen and Find：播放当前单词的发音（不提供文字题干），
选项为 4 个英文单词（1 正确 + 3 个同章节干扰项）。

示例：

```
🔊（播放 "apple"）
A. apple   B. computer   C. beautiful   D. school
```

支持重复播放（听不清再听一次）。

## 5. Game Rules

每局：默认 10 题（当前章节全部知识点；>10 随机抽 10，与既有规则一致）。

来源：当前 Chapter 知识点（不要求已学习，挑战可直接进行）。

时间：每题 8 秒（含播放与作答；听音耗时长于看题，故比极速选择宽限）。
超时按答错处理并自动进入下一题。

得分（Q2 确认后与极速选择差异化）：

- 答对：+10 基础分 + 连击加成（+2 × 当前连击数，复用统一规则）
- **无速度奖励**（听音游戏考准确，不考手速——与极速选择的定位区分）
- 答错/超时：-2（总分下限 0）且连击清零

## 6. Game State

READY → PLAYING → PAUSED → FINISHED → RESULT（与全系列一致）

## 7. Game Page

显示：

- 大播放按钮（🔊，可重复点击播放）
- 每题倒计时（8 秒进度条）
- 当前进度（第 x/10 题）、分数、Combo
- 4 个英文单词选项按钮

退出需要确认。切后台自动暂停（同全系列）。

## 8. Result Page

复用全系列统一结果页（memory-result）：

- 总分、正确数量、错误数量、用时
- 分析：掌握知识 / 薄弱知识（答错 + 超时）
- 按钮：再来一次 / 返回学习 / 加入复习

## 9. Data

- 复用 `memory_game_records`（`gameType: 'listen'`，Chapter 08 §9 的字段设计已覆盖）
- knowledge 集合**不变**：V1 音频实时合成，无需 pronunciation 字段（§16 Q1）
- 音频播放能力：见 §16 Q1（插件/接口/资产三选一）

## 10. Service

新增 ListenFindService（方法与全系列对齐）：

- startGame()
- submitAnswer()
- finishGame()
- saveResult()

实现说明：

- 单词四选一生成器（英文单词作选项，与 quizLogic 的中文释义选项不同）：
  quizLogic 增加 `buildWordChoiceQuestions`，干扰项取同章节其他单词的 word
- 结果登记 `gameResultStore`（复用统一结果页，零新增页面）

## 11. Repository

复用 MemoryGameRepository（写入 gameType='listen'）。

## 12. Learning Integration

与全系列完全一致：

- 答错/超时知识点：生成或更新 review_records（明天复习）
- 答对知识点：masteryLevel + 1
- 触发时机：结果页「加入复习」按钮（复用 reviewService.applyGameResults）

## 13. Default Behavior

- 章节知识点 < 4：提示「本章节知识点不足，敬请期待」
- 音频源不可用（如插件未开通）：明确提示并提供「改用文字题干」降级（可选，见 §16 Q5）
- 网络失败：允许重试
- 退出：不保存本局

## 14. Acceptance Criteria

1. 可以从游戏中心进入听音找词
2. 自动播放当前题单词发音
3. 可重复播放；4 个英文单词选项中选择
4. 每题 8 秒倒计时，超时自动判错并进入下一题
5. 实时显示分数、连击、进度
6. 生成游戏结果（gameType='listen'）
7. 答错/超时知识可加入复习
8. 不影响学习闭环与其他两款游戏

## 15. Principle

听音找词是听力训练工具，不是反应力游戏。
所有题目必须来自学习系统（knowledge 集合，单一来源）。
先完成闭环，再优化动画、音效。
