## 第一章 运动的描述（力学）

### 1.1 质点 参考系
- **定义**：忽略形状和大小、只保留质量的理想化「点」叫质点。
- **讲解**：【规律】物体能否看成质点，看它的大小形状对研究的问题**是否可忽略**（地球公转可看成质点，自转不行）。【易错】质点不是「很小的物体」。
- **例子**：研究地球绕太阳公转时，地球可看成质点。
- **题**：
  1. 下列物体可看成质点的是？ → A. 研究乒乓球的旋转 / B. 研究地球绕太阳的公转 ✓ / C. 研究跳水运动员的动作 / D. 研究火车过桥的时间
  2. 关于质点，下列说法正确的是？ → A. 质点一定是体积很小的物体 / B. 质点是一个理想化模型 ✓ / C. 质点就是有质量的点、无大小 / D. 质点一定是静止的

### 1.2 时间 位移
- **定义**：位移是矢量（初位置指向末位置的有向线段），路程是标量。
- **讲解**：【规律】时刻对应「点」、时间间隔对应「段」；位移是**矢量**（有大小方向）、路程是**标量**（只有大小）。【易错】单向直线运动中，位移大小才等于路程；往返时位移 < 路程。
- **例子**：绕操场跑一圈，路程 400 m，位移为 0。
- **题**：
  1. 下列物理量中是矢量的是？ → A. 路程 / B. 时间 / C. 位移 ✓ / D. 温度
  2. 物体沿直线往返运动回到出发点，位移是？ → A. 等于路程 / B. 为零 ✓ / C. 大于路程 / D. 无法确定

### 1.3 速度
- **定义**：速度是位移与时间的比值，矢量。
- **讲解**：【规律】平均速度 = 位移 ÷ 时间；瞬时速度是某时刻的速度；**速率**是瞬时速度的大小（标量）。【易错】平均速度用**位移**算，不是路程。
- **例子**：汽车速度表显示的是瞬时速度（速率）。
- **题**：
  1. 汽车速度表显示的是？ → A. 平均速度 / B. 瞬时速度（速率）✓ / C. 路程 / D. 加速度
  2. 某物体 4 s 内位移 20 m，平均速度是？ → A. 5 m/s ✓ / B. 80 m/s / C. 0.2 m/s / D. 20 m/s

### 1.4 加速度
- **定义**：加速度是速度的变化量与时间的比值，矢量。
- **讲解**：【规律】a = Δv/Δt，单位 m/s²；方向与**速度变化量**方向相同。【易错】加速度大不等于速度大；加速度为负（减速）时速度可以仍为正。
- **例子**：赛车启动时加速度大、但某一刻速度可能还不大。
- **题**：
  1. 加速度的单位是？ → A. m/s / B. m/s² ✓ / C. m / D. s
  2. 关于加速度，正确的是？ → A. 加速度大速度一定大 / B. 加速度是描述速度变化快慢的物理量 ✓ / C. 加速度为零速度一定为零 / D. 速度大加速度一定大

## 第二章 匀变速直线运动（力学）

### 2.1 速度与时间的关系
- **定义**：匀变速直线运动的速度随时间均匀变化。
- **讲解**：【规律】v = v₀ + at（v₀ 初速度，a 加速度）。【易错】a 与 v₀ 同向加速、反向减速；公式是矢量式，先定正方向。
- **例子**：汽车以 2 m/s² 加速，初速 10 m/s，3 s 后速度 16 m/s。
- **题**：
  1. 物体初速度 4 m/s，加速度 2 m/s²，3 s 末的速度是？ → A. 6 m/s / B. 10 m/s ✓ / C. 12 m/s / D. 8 m/s
  2. 匀变速直线运动，速度与时间的关系式是？ → A. v = v₀ + at ✓ / B. v = at² / C. v = v₀t / D. v = v₀ - a

### 2.2 位移与时间的关系
- **定义**：匀变速直线运动的位移随时间按二次规律变化。
- **讲解**：【规律】x = v₀t + ½at²。【易错】匀加速才带 ½at²；匀减速时 a 取负值代入。
- **例子**：初速 0 的匀加速，2 s 内位移 x = ½at²。
- **题**：
  1. 物体初速度为零，加速度 2 m/s²，2 s 内的位移是？ → A. 2 m / B. 4 m ✓ / C. 8 m / D. 1 m
  2. 匀变速直线运动位移公式是？ → A. x = v₀t + ½at² ✓ / B. x = vt / C. x = v₀ + at / D. x = ½vt

### 2.3 速度与位移的关系
- **定义**：匀变速直线运动中速度平方与位移的关系式。
- **讲解**：【规律】v² − v₀² = 2ax（不涉及时间）。【易错】适用「已知 v₀、a、x 求 v」的场景，避开时间。
- **例子**：汽车刹车（a 为负），已知初速和位移求末速。
- **题**：
  1. 速度与位移的关系式是？ → A. v² − v₀² = 2ax ✓ / B. v = v₀ + 2ax / C. v² = 2a / D. x = v²/a
  2. 汽车初速度 10 m/s，匀减速刹车，加速度大小 2 m/s²，刹车距离是？ → A. 25 m ✓ / B. 50 m / C. 10 m / D. 100 m

### 2.4 自由落体运动
- **定义**：只在重力作用下、从静止开始下落的运动。
- **讲解**：【规律】v = gt，h = ½gt²；g ≈ 9.8 m/s²（方向竖直向下）。【易错】自由落体是初速为 0 的匀加速直线运动；空气阻力忽略不计。
- **例子**：从高处释放小石子，做自由落体运动。
- **题**：
  1. 自由落体运动是？ → A. 匀速直线运动 / B. 初速度为零的匀加速直线运动 ✓ / C. 匀减速运动 / D. 曲线运动
  2. 一物体自由下落，2 s 末的速度约为（g 取 10 m/s²）？ → A. 5 m/s / B. 10 m/s / C. 20 m/s ✓ / D. 40 m/s

## 第三章 相互作用——力（力学）

### 3.1 重力
- **定义**：地球对物体的吸引产生的力。
- **讲解**：【规律】G = mg，方向**竖直向下**，作用点在重心。【易错】重力不是地球对物体的万有引力的全部；重心可在物体外。
- **例子**：物体质量越大，重力越大。
- **题**：
  1. 重力的方向是？ → A. 垂直向下 / B. 竖直向下 ✓ / C. 指向地心 / D. 沿接触面
  2. 质量 2 kg 的物体，重力约为（g 取 10 m/s²）？ → A. 10 N / B. 20 N ✓ / C. 2 N / D. 200 N

### 3.2 弹力
- **定义**：发生弹性形变的物体对与它接触的物体产生的力。
- **讲解**：【规律】胡克定律 F = kx（k 劲度系数，x 形变量）；弹力方向与形变恢复方向相同。【易错】x 是**形变量**不是弹簧长度。
- **例子**：弹簧测力计；拉伸弹簧越长，弹力越大。
- **题**：
  1. 胡克定律的表达式是？ → A. F = kx ✓ / B. F = k/x / C. F = kx² / D. F = mg
  2. 弹力的方向与形变恢复的方向？ → A. 相反 / B. 相同 ✓ / C. 垂直 / D. 无关

### 3.3 摩擦力
- **定义**：相互接触的物体发生相对运动（或有趋势）时产生的阻碍力。
- **讲解**：【规律】滑动摩擦力 f = μN（μ 动摩擦因数，N 压力）；静摩擦力大小由平衡条件定（范围 0 ~ fmax）。【易错】滑动摩擦力与**压力**成正比，不是与重力成正比。
- **例子**：推箱子匀速运动，推力等于滑动摩擦力。
- **题**：
  1. 滑动摩擦力的大小与什么成正比？ → A. 重力 / B. 压力 ✓ / C. 速度 / D. 接触面积
  2. 滑动摩擦力公式是？ → A. f = μN ✓ / B. f = μmg / C. f = kx / D. f = ma

### 3.4 力的合成与分解
- **定义**：力的合成与分解都遵循平行四边形定则。
- **讲解**：【规律】两力合成，合力范围 |F₁−F₂| ≤ F ≤ F₁+F₂；正交分解是最常用的分解方法。【易错】合力不一定大于分力。
- **例子**：两人沿同方向推箱子，合力等于两力之和。
- **题**：
  1. 两个力 3 N 和 4 N，方向相反，合力是？ → A. 7 N / B. 1 N ✓ / C. 5 N / D. 12 N
  2. 力的合成遵循？ → A. 平行四边形定则 ✓ / B. 牛顿定律 / C. 胡克定律 / D. 万有引力定律

## 第四章 牛顿运动定律（力学）

### 4.1 牛顿第一定律
- **定义**：一切物体总保持匀速直线运动或静止状态，直到外力迫使它改变。
- **讲解**：【规律】又叫**惯性定律**；惯性是物体的固有属性，只与**质量**有关。【易错】力不是维持运动的原因，是改变运动状态的原因。
- **例子**：刹车时人向前倾（惯性）。
- **题**：
  1. 牛顿第一定律又叫？ → A. 惯性定律 ✓ / B. 加速度定律 / C. 作用力反作用力定律 / D. 万有引力定律
  2. 惯性的大小只与什么有关？ → A. 速度 / B. 质量 ✓ / C. 受力 / D. 形状

### 4.2 牛顿第二定律
- **定义**：物体加速度与合外力成正比、与质量成反比。
- **讲解**：【规律】F = ma（F 是**合外力**，单位 N）；1 N = 1 kg·m/s²。【易错】F 是合外力，不是某一个力。
- **例子**：质量 2 kg 的物体受 6 N 合外力，加速度 3 m/s²。
- **题**：
  1. 牛顿第二定律的表达式是？ → A. F = ma ✓ / B. F = mv / C. F = mg / D. F = kx
  2. 质量 3 kg 的物体受 6 N 合外力，加速度是？ → A. 2 m/s² ✓ / B. 18 m/s² / C. 0.5 m/s² / D. 3 m/s²

### 4.3 牛顿第三定律
- **定义**：作用力和反作用力大小相等、方向相反、作用在同一直线上。
- **讲解**：【规律】作用力与反作用力**同时产生、同时消失**，性质相同。【易错】作用力与反作用力作用在**两个不同物体**上，不能抵消；一对平衡力才作用在同一物体上。
- **例子**：划船时桨向后推水，水向前推船。
- **题**：
  1. 作用力与反作用力的大小关系是？ → A. 大小相等 ✓ / B. 作用力大 / C. 反作用力大 / D. 不一定
  2. 作用力与反作用力作用在？ → A. 同一物体上 / B. 两个不同物体上 ✓ / C. 都可以 / D. 没有物体

### 4.4 超重和失重
- **定义**：物体对支持物的压力（或拉力）大于重力叫超重，小于重力叫失重。
- **讲解**：【规律】加速度**向上**超重、**向下**失重；完全失重时 a = g。【易错】超重失重看**加速度方向**，不是速度方向；超重时重力本身不变。
- **例子**：电梯加速上升时超重；加速下降时失重。
- **题**：
  1. 电梯加速上升时，人处于？ → A. 超重状态 ✓ / B. 失重状态 / C. 平衡状态 / D. 无法判断
  2. 超重时，物体的重力？ → A. 变大 / B. 不变 ✓ / C. 变小 / D. 为零
