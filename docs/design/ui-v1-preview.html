㉑ 分数模型（B-7 第 2 个可视化组件） —— 一根条 = 一个整体，按分母等分、分子涂色。 假分数化成带分数再画（5/4 → 1 又 1/4 的两个整体）， 不是在 4 等分的条上涂 5 段 —— 那样学生数不清有几个整体。 比大小看长度不看份数；1/2 与 2/4 判等（留了浮点容差）

㉒ 平面直角坐标系（B-7 第 3 个，canvas 2d） —— 网格 + 轴 + 刻度 + 描点 + 一次函数 y = kx + b。 所有像素坐标在 utils/coordinatePlane.ts 算好并单测，组件只管描线。 0 不在范围内时轴自动贴边框；函数线裁剪在绘图区内，不会盖住刻度数字
