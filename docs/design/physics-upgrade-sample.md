## 2.1 速度与时间的关系

- **是什么**：汽车踩油门，速度表指针一秒比一秒转得快——速度在「均匀」地变大。
- **为什么**：匀变速的意思是「每过 1 秒，速度都增加同样多」。初速度是 v₀，每秒多一个 a，过了 t 秒就多了 a·t，所以末速度 = 初速度 + 增量。
- **结论**：**v = v₀ + at**
- **怎么用**：a 与 v₀ 同向是加速、反向是减速（减速时代入 a 为负）；先定正方向，再套公式。
- **题**：
  1. 【基础】物体初速度 4 m/s，加速度 2 m/s²，3 秒末的速度是？ → 4+2×3 = **10 m/s** ✓
  2. 【应用】汽车初速度 10 m/s，以 2 m/s² 的加速度刹车（a 取 −2），2 秒末速度是？ → 10−2×2 = **6 m/s** ✓
  3. 【综合·配图】看下面的 v-t 图（初速度 2 m/s，匀加速），4 秒末的速度是多少？
     - `visual: coordinate-plane { xMin:0, xMax:5, yMin:0, yMax:16, lineK:3, lineB:2 }`
     - 读图：t=4 时 v = 2+3×4 = **14 m/s** ✓

## 2.2 位移与时间的关系

- **是什么**：物体越跑越快时，它走过的路不是「速度 × 时间」这么简单——因为速度一直在变。
- **为什么**：把「匀加速」看成「初速度匀速 + 加速度额外叠加」两段：匀速部分走 v₀t，加速部分额外走 ½at²（可用 v-t 图下面积想通：梯形面积 = 矩形 + 三角形）。
- **结论**：**x = v₀t + ½at²**
- **怎么用**：初速度为 0 时简化为 x = ½at²；匀减速时 a 代负值。
- **题**：
  1. 【基础】物体从静止出发，加速度 2 m/s²，2 秒内位移？ → ½×2×2² = **4 m** ✓
  2. 【应用】初速度 5 m/s、加速度 2 m/s²，3 秒内位移？ → 5×3 + ½×2×9 = **24 m** ✓
  3. 【综合·配图】v-t 图是一条过原点的斜线（斜率 a=2）。2 秒内位移等于图线下方三角形面积，是？
     - `visual: coordinate-plane { xMin:0, xMax:3, yMin:0, yMax:6, lineK:2, lineB:0 }`
     - 面积 = ½×2×4 = **4 m** ✓

## 2.3 速度与位移的关系

- **是什么**：刹车时，我们常问「以这个速度刹车，还要滑多远才停」——这里没有「时间」信息，只有初速度、末速度和加速度。
- **为什么**：由 v = v₀ + at 和 x = v₀t + ½at² 两个式子，把时间 t 消掉，就得到一个不含 t 的关系式。
- **结论**：**v² − v₀² = 2ax**
- **怎么用**：已知「初速度、末速度、加速度、位移」中任意三个求第四个、且不关心时间时用它。
- **题**：
  1. 【基础】物体初速度 0，加速度 2 m/s²，位移 4 m 时速度？ → v² = 2×2×4 = 16，**v = 4 m/s** ✓
  2. 【应用】汽车初速度 20 m/s，刹车后末速度 0，加速度大小 5 m/s²（a=−5），刹车距离？ → 0−400 = 2×(−5)x，**x = 40 m** ✓
  3. 【综合】同一段位移，初速度翻倍（加速度相同），末速度会？ → v² 与初速度平方线性，**不是简单翻倍**（末速度变为 √(v₀²翻倍) 的关系）✓

## 2.4 自由落体运动

- **是什么**：把石头从手里松开放下，它越落越快——这是最典型的匀加速运动。
- **为什么**：只受重力、从静止开始，加速度恒为重力加速度 g（≈9.8 m/s²，取 10 更简单），初速度是 0。
- **结论**：**v = gt，h = ½gt²**
- **怎么用**：自由落体就是「v₀=0、a=g」的匀加速；空气阻力忽略不计才算自由落体。
- **题**：
  1. 【基础】物体自由下落 2 秒末速度（g 取 10）？ → 10×2 = **20 m/s** ✓
  2. 【应用】物体自由下落 2 秒下落的高度（g 取 10）？ → ½×10×4 = **20 m** ✓
  3. 【综合·配图】自由落体的 v-t 图是一条过原点、斜率 g 的直线。下落 1 s、2 s、3 s 的速度之比是？
     - `visual: coordinate-plane { xMin:0, xMax:4, yMin:0, yMax:40, lineK:10, lineB:0 }`
     - v=gt，所以 **1 : 2 : 3** ✓
