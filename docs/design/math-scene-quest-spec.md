# 「情景应用闯关」题型规格（数学 + 英语）

> 状态：**已拍板，实施中**。2026-09-17 Owner 拍板三件事：
> ① **补齐一二年级**；② **英语版也要做**；③ **现在不进错题本**（等 L3 打通错题回流后再评估）。
>
> 本文 §5 保留了最初用来确认笔法与难度的 4 组样题（共 16 问）；正式内容已按拍板扩写，
> 落在 `config/mathScenes.ts` + `config/englishScenes.ts`。

## 1. 背景：我们缺什么

自有数学题库 320 道里，只有 **24 道**带生活情景，且基本**一步到位**：

> 树上有 2 只小鸟，又飞来 3 只，一共有几只？

真正的「应用能力」题长这样——**几问连在一个故事上，越往后越要拐一个弯**：

> 先算总价 → 再算找零 → 然后发现商品降价了 → 最后用找回的钱再买一样东西。

这类题考的不是计算，是「**题目在说什么**」——孩子做错往往不是不会算，是没读懂要他算什么。
我们目前一道都没有。

## 2. 一个必须先说清的结论：它**不能走单元测试池**

`testService.buildPaper` 是按章节**随机抽题**组卷的。把 4 问共享的故事塞进去，
抽出来很可能是「第 3 问在第 2 题、第 1 问在第 17 题」——**故事会被打散，第 2 问的前提不见了**。

所以：

- ❌ 不做成 `knowledge.quiz[]`（会漏进单元测试）；
- ✅ 做成**独立的情景闯关**，一组题**连着做完**，像冒险岛那样有自己的入口。

> 关联：等 L3 打通「错题回流」之后再决定要不要搬进 `knowledge` 集合。
> 现在搬进去既污染概念列表，也会被单元测试抽散。

## 3. 数据契约（已定稿）

类型在 `core/scene.ts`（纯类型 + 纯函数），数据分别在 `config/mathScenes.ts` /
`config/englishScenes.ts`——**只放数据**，与 `config/mathIsland.ts` 关卡表同一套约定。

```ts
export interface SceneQuestion {
  readonly stem: string; // 题干（自带解答本题所需的全部数据，见 §4）
  readonly options: readonly string[]; // 4 选 1
  readonly answerIndex: number;
  readonly hint: string; // 第一次错给的提示（**不给答案**）
  readonly explain: string; // 第二次错 / 答完后给的讲解
}

export interface SceneQuest {
  readonly id: string;
  readonly name: string;
  readonly story: string; // 情景卡文字，整组共享
  readonly grade?: number; // 适用年级下限，走 ADR-012 的 withinGrade 过滤
  readonly questions: readonly SceneQuestion[]; // 4 问
}

export interface ScenePack {
  readonly id: string;
  readonly subject: '数学' | '英语';
  readonly name: string; // 超市购物
  readonly icon: string;
  readonly desc: string;
  readonly quests: readonly SceneQuest[]; // 按 grade 升序
}
```

**判题不经过 `questionJudge`**：场景题是自带 `answerIndex` 的 4 选 1，判定放 `core/scene.ts`
的纯函数即可，不必绕 `Question` 那层。**题型仍然是 0 个新增**（`core/question.ts` 一行没动）。

**年级过滤复用 `services/gradeScope.withinGrade`**（口径唯一，ADR-012）：
`grade` 是「学到这个年级才会做」的下限，**高年级仍能看到前面的**（复习需要累积）。
数学每个场景给 **一年级 / 三~~四年级 / 五~~六年级** 三组，英语给 **三~~四年级 / 五~~六年级** 两组
（英语从三年级起，一二年级不开）。

## 4. 四条内容铁律（写题时必须守）

1. **每题自带所需数据**——不能要求孩子「记住上一问算出来的数」。
   故事连贯，但**每问独立可解**。
2. **不连锁惩罚**——第 1 问答错，第 2 问照样能做。多步是「情境递进」，不是「连环扣」。
3. **小学讲画面，不复述定义**（既有学段笔法口径）。讲解给「怎么想的」，
   不给「什么叫总价」这类课本定义。
4. **数字要经得起算**——单位统一、结果取整或到角分，不出现除不尽还硬凑的题。

## 5. 四个场景 · 样题（各 1 组 4 问）

### 场景一 🛒 超市购物（三年级 · 加减与元角分）

> **情景卡**：周六妈妈给你 50 元，让你去楼下超市买三样东西：牛奶 12 元，面包 8 元，苹果 15 元。

| #   | 题干                                                      | 选项                  | 正确 |
| --- | --------------------------------------------------------- | --------------------- | ---- |
| 1   | 三样一共多少元？                                          | 33 / **35** / 37 / 39 | 35   |
| 2   | 你付给收银员 50 元，应找回多少元？                        | 13 / **15** / 17 / 20 | 15   |
| 3   | 结账前发现苹果降价 3 元，现在三样一共多少元？             | 30 / **32** / 34 / 35 | 32   |
| 4   | 回家路上，你用找回的 15 元买了一支 4 元的笔，还剩多少元？ | 9 / **11** / 13 / 15  | 11   |

- 第 1 问提示：先把三个价格摞起来加，别急着想后面的。
- 第 2 问讲解：付出去的钱减掉花的钱就是找回的钱，50 − 35 = 15。
- 第 3 问提示：只有苹果便宜了 3 元，牛奶和面包没变。
- 第 4 问讲解：这一问只跟「找回的 15 元」有关，跟苹果降没降价没关系——**看清楚题目问的是哪件事**。

### 场景二 🧃 分果汁（四年级 · 容量换算与整倍数）

> **情景卡**：班级聚会，老师买了 3 大瓶果汁，每瓶 2 升。班上一共 24 个同学，每人一杯，每杯 200 毫升。

| #   | 题干                                        | 选项                                                | 正确    |
| --- | ------------------------------------------- | --------------------------------------------------- | ------- |
| 1   | 3 瓶果汁一共多少毫升？                      | 600 / **6000** / 60000 / 3000                       | 6000    |
| 2   | 24 个同学一共需要多少毫升？                 | 2400 / 4200 / **4800** / 5200                       | 4800    |
| 3   | 果汁够分吗？够的话多出多少毫升？            | 不够，差 1200 / **够，多 1200** / 够，多 800 / 刚好 | 多 1200 |
| 4   | 多出来的果汁还能再倒几杯（每杯 200 毫升）？ | 4 / 5 / **6** / 8                                   | 6       |

- 第 1 问讲解：先换单位——1 升 = 1000 毫升，2 升就是 2000 毫升，3 瓶是 6000 毫升。**单位不一样不能直接比**。
- 第 2 问提示：一人 200 毫升，24 人就是 24 个 200。
- 第 3 问讲解：拿「有的」减「要的」，6000 − 4800 = 1200。
- 第 4 问提示：看看 1200 里面有几个 200。

### 场景三 🚗 去外婆家（五年级 · 时间、小数与速度）

> **情景卡**：全家开车去外婆家，全程 180 千米。出发时上午 8:30，中途休息 30 分钟，到达时是 11:30。

| #   | 题干                                                 | 选项                  | 正确 |
| --- | ---------------------------------------------------- | --------------------- | ---- |
| 1   | 从头到尾一共用了多少小时（含休息）？                 | 2.5 / **3** / 3.5 / 2 | 3    |
| 2   | 真正开车在路上的时间是多少小时？                     | 2 / **2.5** / 3 / 1.5 | 2.5  |
| 3   | 开车时平均每小时行多少千米？                         | 60 / **72** / 80 / 90 | 72   |
| 4   | 回程走高速，速度提高到每小时 90 千米，需要多少小时？ | 1.5 / **2** / 2.5 / 3 | 2    |

- 第 1 问提示：8:30 到 11:30 经过了几个整点？
- 第 2 问讲解：休息的 30 分钟是**半个**小时，要减掉，3 − 0.5 = 2.5。
- 第 3 问讲解：速度 = 路程 ÷ 时间，而且要用**开车的时间**，不是含休息的 3 小时。
- 第 4 问提示：路程还是 180 千米，这回速度换成了 90。

### 场景四 💰 零花钱管理（六年级 · 百分数与折扣）

> **情景卡**：你的存钱罐里有 200 元。商店做活动，文具全部八折。你看中一支原价 25 元的钢笔和一个原价 40 元的书包。

| #   | 题干                             | 选项                                                | 正确   |
| --- | -------------------------------- | --------------------------------------------------- | ------ |
| 1   | 「八折」是什么意思？             | **付原价的 80%** / 少付 80 元 / 付 8 元 / 少付 8 元 | 付 80% |
| 2   | 钢笔打折后多少元？               | 18 / **20** / 22 / 5                                | 20     |
| 3   | 钢笔和书包一共要付多少元？       | 45 / **52** / 58 / 65                               | 52     |
| 4   | 买完这两样，存钱罐里还剩多少元？ | 138 / **148** / 152 / 158                           | 148    |

- 第 1 问讲解：「几折」就是「原价的十分之几」，八折 = 原价的 80%。
- 第 2 问提示：25 的 80% 是多少？
- 第 3 问讲解：可以先打完折再加，也可以先加再打折——(25 + 40) × 0.8 = 52，两种算法结果一样。
- 第 4 问讲解：200 − 52 = 148。别把「打折省下的钱」当成「花掉的钱」。

## 9. 低年级读题（Owner 2026-09-18 追加）

> 原话：「低年级的识字率不高，所以要能语音读题，这个是自动的，可以手动关闭。」

一年级孩子能把「5 以内数的认识和加、减法」读下来就不错了，更别说题干里的「找零」「一共」。
所以题目要**念给他听**。

| 项 | 方案 |
| --- | --- |
| 引擎 | `utils/readAloud.ts`（合成 / 播放 / 缓存 / 开关），合成端口在 `utils/tts.ts` |
| 默认 | **开**。存的是「关」标记（`read_aloud_off_v1`），所以老用户升级上来也是开的 |
| 手动关 | 答题页顶部「自动读题：开 / 关」一点即切，跨会话记住 |
| 读什么 | 进组：情景卡 + 第一问；换题：该题；答完：提示 / 讲解 |
| 中英混排 | 英语题的**题干是中文、选项是英文**，必须分段换语言念（中文声音念英文会把孩子带偏） |
| 节奏 | 朗读开着时**念完再跳下一题**，否则声音会被切在半句话上 |
| 降级 | 插件没开通 / 当日配额用完 / 文本过长 ⇒ 不朗读、不报错、**不崩**；连续失败 3 次本次会话不再试 |
| 配额 | 合成结果按「语言 + 文本」缓存（上限 80 条），「再读一遍」命中缓存不再花钱 |

⚠️ 语音合成走**微信同声传译插件**（`app.json` 已声明 0.3.5），与英语单词发音同一套。
插件调用已收敛到 `utils/tts.ts` 一处——两个调用点各写一遍 `requirePlugin` 迟早走散。

**当前只接在情景闯关答题页**（低年级内容就在这）。学习详情（概念讲解）、测试、复习
这些页面同样吃识字率，可以按同一套接上去——等 Owner 定范围。
