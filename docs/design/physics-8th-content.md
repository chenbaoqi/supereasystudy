## 第一章 机械运动（力学）

### 1.1 长度和时间的测量
- **定义**：用刻度尺测量长度、用停表测量时间。
- **讲解**：【单位】长度主单位米(m)，1 m = 10 dm = 100 cm = 1000 mm；时间主单位秒(s)。【测量】刻度尺读数要**估读到分度值的下一位**。【易错】**误差**不可避免、只能减小（多次测量取平均）；**错误**可以避免。
- **例子**：一张课桌高约 80 cm；人正常步行速度约 1.1 m/s。
- **题**：
  1. 下列长度单位换算正确的是？ → A. 1 m = 10 dm ✓ / B. 1 m = 100 dm / C. 1 m = 10 cm / D. 1 m = 100 mm
  2. 关于误差，下列说法正确的是？ → A. 误差可以完全避免 / B. 误差就是错误 / C. 多次测量取平均值可以减小误差 ✓ / D. 误差是由测量工具损坏造成的

### 1.2 运动的描述
- **定义**：判断物体运动还是静止，要看它相对于**参照物**的位置是否变化。
- **讲解**：【规律】机械运动是物体位置随时间的变化；描述运动时要先选**参照物**。【易错】同一物体选不同参照物，运动情况可能不同——**运动和静止是相对的**。
- **例子**：「两岸青山相对出」——以船为参照物，山是运动的。
- **题**：
  1. 坐在行驶列车上的乘客，以地面为参照物是？ → A. 静止的 / B. 运动的 ✓ / C. 无法判断 / D. 有时静止有时运动
  2. 「两岸青山相对出，孤帆一片日边来」，前一句的参照物是？ → A. 岸 / B. 地面 / C. 船（诗人）✓ / D. 太阳

### 1.3 运动的快慢
- **定义**：速度是描述物体运动快慢的物理量。
- **讲解**：【规律】速度 v = s/t，单位米每秒(m/s)，常用 km/h；**1 m/s = 3.6 km/h**。【易错】匀速直线运动是速度不变的运动；**平均速度** = 总路程 ÷ 总时间（不是速度的平均）。
- **例子**：汽车仪表盘 60 km/h；百米赛跑约 8 m/s。
- **题**：
  1. 72 km/h 等于多少 m/s？ → A. 10 m/s / B. 20 m/s ✓ / C. 30 m/s / D. 72 m/s
  2. 某物体 10 s 内通过 50 m，它的速度是？ → A. 5 m/s ✓ / B. 50 m/s / C. 0.2 m/s / D. 2 m/s

### 1.4 测量平均速度
- **定义**：用刻度尺测路程、停表测时间，算出平均速度。
- **讲解**：【实验】测小车在斜面上的平均速度，v = s/t。【易错】斜面**坡度要小**（便于计时，减小误差）；测的是**平均速度**不是某一瞬间的速度。
- **例子**：测小车从斜面顶端滑到底端的平均速度。
- **题**：
  1. 测小车平均速度时，斜面的坡度应？ → A. 尽量大，省时间 / B. 尽量小，便于计时 ✓ / C. 竖直放置 / D. 任意角度都一样
  2. 测平均速度需要测的两个量是？ → A. 质量和体积 / B. 路程和时间 ✓ / C. 速度和路程 / D. 时间和速度

## 第二章 声现象（声学）

### 2.1 声音的产生与传播
- **定义**：声音由物体**振动**产生，靠**介质**传播。
- **讲解**：【规律】声音靠振动产生（一切发声体都在振动）；声音传播需要**介质**（固体、液体、气体），**真空不能传声**。【易错】声音在固体中最快、液体次之、气体最慢；15℃ 空气中声速约 340 m/s。
- **例子**：说话时手摸喉咙会感到振动；宇航员在月球上要靠无线电通话（真空不能传声）。
- **题**：
  1. 声音是由物体的什么产生的？ → A. 振动 ✓ / B. 运动 / C. 温度 / D. 摩擦
  2. 关于声音的传播，正确的是？ → A. 声音能在真空中传播 / B. 声音只能在空气中传播 / C. 声音在固体中比在空气中传播快 ✓ / D. 声音传播不需要介质

### 2.2 声音的特性
- **定义**：声音有**音调、响度、音色**三个特性。
- **讲解**：【规律】音调由**频率**决定（频率高音调高）；响度由**振幅**和距离决定（振幅大响度大）；音色由**发声体本身**决定（区分不同人/乐器）。【易错】音调是「高不高」，响度是「响不响」，别混。
- **例子**：女高音「高」是音调高；「大声说」是响度大；能听出是谁在说话靠音色。
- **题**：
  1. 音调的高低由什么决定？ → A. 振幅 / B. 频率 ✓ / C. 传播距离 / D. 介质种类
  2. 我们能「闻其声知其人」，靠的是声音的？ → A. 音调 / B. 响度 / C. 音色 ✓ / D. 频率

### 2.3 声的利用
- **定义**：声音可以传递**信息**，也可以传递**能量**。
- **讲解**：【规律】回声定位（蝙蝠、声呐）、B 超、听诊器传递的是**信息**；超声波清洗、碎石传递的是**能量**。【易错】区分「传递信息」还是「传递能量」。
- **例子**：蝙蝠靠回声定位捕食；医生用 B 超检查；超声波清洗眼镜。
- **题**：
  1. 蝙蝠捕食利用的是声音传递？ → A. 能量 / B. 信息 ✓ / C. 温度 / D. 光
  2. 用超声波清洗眼镜，说明声音能传递？ → A. 信息 / B. 能量 ✓ / C. 热量 / D. 声音本身

### 2.4 噪声的危害和控制
- **定义**：噪声的等级用**分贝(dB)**表示，控制在声源、传播、接收三处。
- **讲解**：【规律】从**声源处**（禁鸣喇叭）、**传播中**（隔音墙）、**人耳处**（戴耳塞）三方面控制噪声。【易错】30~40 dB 是较安静环境；噪声不等同于「难听的声音」——判断噪声看「是否影响休息/学习/工作」。
- **例子**：禁鸣标志是声源处控制；高架隔音墙是传播中控制。
- **题**：
  1. 城市禁鸣喇叭，是在哪个环节控制噪声？ → A. 声源处 ✓ / B. 传播过程中 / C. 人耳处 / D. 无法控制
  2. 戴耳塞降噪，是在哪个环节控制？ → A. 声源处 / B. 传播过程中 / C. 人耳处 ✓ / D. 都不是

## 第三章 物态变化（热学）

### 3.1 温度
- **定义**：温度表示物体的**冷热程度**，用温度计测量。
- **讲解**：【单位】摄氏度(℃)。【规律】摄氏温标：冰水混合物为 0℃，标准大气压下沸水为 100℃。【易错】体温计有**缩口**，读数后可以离开人体；读数时视线要与液柱**平齐**。
- **例子**：人的正常体温约 37℃；读数时俯视会读偏大、仰视读偏小。
- **题**：
  1. 摄氏温标规定，冰水混合物的温度是？ → A. 100℃ / B. 0℃ ✓ / C. 37℃ / D. -273℃
  2. 体温计可以离开人体读数，是因为它有？ → A. 刻度 / B. 玻璃泡 / C. 缩口 ✓ / D. 水银

### 3.2 熔化和凝固
- **定义**：熔化（固→液，吸热）、凝固（液→固，放热）。
- **讲解**：【规律】晶体有**固定熔点**（冰 0℃），非晶体没有；晶体熔化时**吸热但温度不变**。【易错】熔化吸热、凝固放热，别记反。
- **例子**：冰雪消融是熔化；水结成冰是凝固。
- **题**：
  1. 冰熔化成水，属于？ → A. 吸热的物态变化 ✓ / B. 放热的物态变化 / C. 温度升高的过程 / D. 化学变化
  2. 晶体在熔化过程中，温度？ → A. 持续升高 / B. 持续降低 / C. 保持不变 ✓ / D. 先升后降

### 3.3 汽化和液化
- **定义**：汽化（液→气，吸热）、液化（气→液，放热）。
- **讲解**：【规律】汽化有两种：**蒸发**（任何温度、只在表面）和**沸腾**（达到沸点、内部表面同时）；液化是汽化的逆过程。【易错】蒸发吸热有**致冷作用**（擦酒精感觉凉）；「白气」是**液化**（水蒸气遇冷液化成小水珠）。
- **例子**：烧开水是沸腾；湿衣服晾干是蒸发；夏天冰棒冒「白气」是液化。
- **题**：
  1. 擦酒精后皮肤感到凉，是因为酒精蒸发时？ → A. 放热 / B. 吸热 ✓ / C. 不吸热不放热 / D. 温度升高
  2. 冰棒周围冒「白气」，是水蒸气发生了？ → A. 汽化 / B. 液化 ✓ / C. 熔化 / D. 升华

### 3.4 升华和凝华
- **定义**：升华（固→气，吸热）、凝华（气→固，放热）。
- **讲解**：【规律】升华吸热、凝华放热；樟脑丸变小、冰冻衣服变干是升华；霜、窗花、雾凇是凝华。【易错】「霜」是水蒸气**直接凝华**成的固体，不是先液化再凝固。
- **例子**：衣柜里樟脑丸变小是升华；冬天窗户上结「窗花」是凝华。
- **题**：
  1. 樟脑丸慢慢变小直到消失，属于？ → A. 升华 ✓ / B. 凝华 / C. 汽化 / D. 熔化
  2. 冬天清晨地面上的霜，是水蒸气发生了？ → A. 汽化 / B. 液化 / C. 升华 / D. 凝华 ✓

## 第四章 光现象（光学）

### 4.1 光的直线传播
- **定义**：光在**同种均匀介质**中沿直线传播。
- **讲解**：【规律】影子的形成、日食月食、小孔成像都是光的直线传播；光速真空中约 3×10⁸ m/s（光速 > 声速）。【易错】小孔成像成的是**倒立**的实像。
- **例子**：手影、小孔成像、日食月食。
- **题**：
  1. 下列现象由光的直线传播形成的是？ → A. 水中倒影 / B. 小孔成像 ✓ / C. 雨后彩虹 / D. 镜中花
  2. 光在真空中的传播速度约为？ → A. 340 m/s / B. 3×10⁸ m/s ✓ / C. 3×10⁵ m/s / D. 3×10¹⁰ m/s

### 4.2 光的反射
- **定义**：光射到物体表面被**反射**回去的现象。
- **讲解**：【规律】反射定律：反射角**等于**入射角，反射光线、入射光线、法线在**同一平面**内。【易错】镜面反射和漫反射**都遵循反射定律**；入射角是入射光线与**法线**的夹角（不是与镜面）。
- **例子**：平面镜成像、黑板反光（镜面反射）、从各个方向看到物体（漫反射）。
- **题**：
  1. 入射光线与法线成 40° 角，反射角是？ → A. 40° ✓ / B. 50° / C. 80° / D. 20°
  2. 我们能从不同方向看到不发光的物体，是因为光在物体表面发生了？ → A. 镜面反射 / B. 漫反射 ✓ / C. 折射 / D. 色散

### 4.3 平面镜成像
- **定义**：平面镜成正立、等大的**虚像**。
- **讲解**：【规律】像与物**大小相等**、到镜面**距离相等**、连线与镜面垂直，成的是**虚像**。【易错】像的大小与物体到镜子的距离无关（人走近镜子，像大小不变）。
- **例子**：照镜子、平静水面上的倒影。
- **题**：
  1. 人站在平面镜前，像的大小与什么有关？ → A. 人到镜的距离 / B. 镜的大小 / C. 人自身的大小 ✓ / D. 观察角度
  2. 平面镜所成的像是？ → A. 倒立的实像 / B. 正立的虚像 ✓ / C. 倒立的虚像 / D. 正立的实像

### 4.4 光的折射
- **定义**：光从一种介质斜射入另一种介质时，传播方向发生**偏折**。
- **讲解**：【规律】光从空气斜射入水中，折射角**小于**入射角（靠近法线）；从水中斜射入空气，折射角**大于**入射角。【易错】池水看起来比实际**浅**，是光的折射。
- **例子**：筷子在水中「折断」、池水变浅、海市蜃楼。
- **题**：
  1. 插入水中的筷子看起来向上弯折，这是光的？ → A. 反射 / B. 折射 ✓ / C. 直线传播 / D. 色散
  2. 光从空气斜射入水中，折射角与入射角的关系是？ → A. 折射角大于入射角 / B. 折射角小于入射角 ✓ / C. 两角相等 / D. 无法确定

### 4.5 光的色散
- **定义**：白光（太阳光）通过三棱镜分解成**七种色光**的现象。
- **讲解**：【规律】白光由红橙黄绿蓝靛紫七色光组成；色光三原色是**红、绿、蓝**。【易错】彩虹是光的**色散**（折射的一种）；透明物体的颜色由它**透过的色光**决定。
- **例子**：雨后彩虹、三棱镜分解白光。
- **题**：
  1. 雨后彩虹是光的什么现象？ → A. 反射 / B. 色散 ✓ / C. 直线传播 / D. 平面镜成像
  2. 色光的三原色是？ → A. 红黄蓝 / B. 红绿蓝 ✓ / C. 红黄绿 / D. 黄绿蓝

## 第五章 透镜及其应用（光学）

### 5.1 透镜
- **定义**：凸透镜**中间厚边缘薄**，对光有**会聚**作用；凹透镜中间薄边缘厚，对光有**发散**作用。
- **讲解**：【规律】凸透镜焦点到光心的距离叫**焦距**；凸透镜使平行光会聚于焦点。【易错】会聚/发散不是指光线「相交」，而是相对原传播方向「更靠拢/更散开」。
- **例子**：放大镜是凸透镜；近视眼镜片是凹透镜。
- **题**：
  1. 对光有会聚作用的透镜是？ → A. 凹透镜 / B. 凸透镜 ✓ / C. 平面镜 / D. 三棱镜
  2. 凸透镜是？ → A. 中间薄边缘厚 / B. 中间厚边缘薄 ✓ / C. 中间边缘一样厚 / D. 任意形状

### 5.2 生活中的透镜
- **定义**：照相机、投影仪、放大镜都是凸透镜的应用。
- **讲解**：【规律】照相机成**倒立缩小**实像；投影仪成**倒立放大**实像；放大镜成**正立放大**虚像。【易错】三种情况的物距不同：照相机物距最大、放大镜物距最小（物距小于焦距）。
- **例子**：拍照、投影仪投屏、放大镜看字。
- **题**：
  1. 照相机成的是？ → A. 正立缩小的虚像 / B. 倒立缩小的实像 ✓ / C. 正立放大的实像 / D. 倒立放大的虚像
  2. 用放大镜看字，字通过放大镜成的是？ → A. 倒立放大的实像 / B. 正立放大的虚像 ✓ / C. 倒立缩小的实像 / D. 正立等大的虚像

### 5.3 凸透镜成像的规律
- **定义**：凸透镜成像规律随**物距**变化。
- **讲解**：【规律】物距大于 2 倍焦距 → 倒立缩小实像；等于 2 倍焦距 → 倒立等大；1 倍到 2 倍焦距之间 → 倒立放大实像；小于 1 倍焦距 → 正立放大虚像。【易错】**1 倍焦距分虚实，2 倍焦距分大小**；实像倒立、虚像正立。
- **例子**：蜡烛靠近凸透镜，像的变化。
- **题**：
  1. 物体在凸透镜 2 倍焦距之外，成的是？ → A. 倒立缩小的实像 ✓ / B. 正立放大的虚像 / C. 倒立放大的虚像 / D. 正立缩小的实像
  2. 物体在凸透镜 1 倍焦距以内，成的是？ → A. 倒立实像 / B. 正立放大的虚像 ✓ / C. 倒立缩小的实像 / D. 正立缩小的虚像

### 5.4 眼睛和眼镜
- **定义**：眼睛的晶状体相当于**凸透镜**，视网膜相当于**光屏**。
- **讲解**：【规律】近视眼看不清远处，像成在视网膜**前**，用**凹透镜**矫正；远视眼看不清近处，像成在视网膜**后**，用**凸透镜**矫正。【易错】近视=凹透镜，远视=凸透镜，别记反。
- **例子**：近视眼戴凹透镜眼镜；老花眼（远视）戴凸透镜。
- **题**：
  1. 近视眼应配戴什么透镜矫正？ → A. 凸透镜 / B. 凹透镜 ✓ / C. 平面镜 / D. 三棱镜
  2. 眼睛的晶状体相当于？ → A. 凹透镜 / B. 凸透镜 ✓ / C. 平面镜 / D. 光屏

### 5.5 显微镜和望远镜
- **定义**：显微镜和望远镜都由多组透镜组成。
- **讲解**：【规律】显微镜：物镜成倒立放大实像、目镜成放大虚像（看清微小物体）；望远镜：物镜成倒立缩小实像、目镜成放大虚像（看清远处物体）。【易错】显微镜看清**微小**，望远镜看清**远处**。
- **例子**：显微镜观察细胞，望远镜观察星空。
- **题**：
  1. 显微镜用来观察？ → A. 远处物体 / B. 微小物体 ✓ / C. 彩色物体 / D. 快速运动的物体
  2. 望远镜用来观察？ → A. 微小物体 / B. 远处物体 ✓ / C. 无色物体 / D. 静止物体

## 第六章 质量与密度（力学）

### 6.1 质量
- **定义**：质量表示物体所含**物质的多少**，单位千克(kg)。
- **讲解**：【规律】质量是物体的属性，**不随位置、形状、状态、温度改变**（宇航员到月球质量不变）。【易错】质量不是重量；天平测的是质量不是重力。
- **例子**：一块冰熔化成水，质量不变；物体从地球到月球质量不变。
- **题**：
  1. 下列物理量中，不随位置改变的是？ → A. 重力 / B. 质量 ✓ / C. 温度 / D. 体积
  2. 质量的国际单位是？ → A. 克 / B. 千克 ✓ / C. 牛 / D. 吨

### 6.2 密度
- **定义**：密度是物质的一种特性，表示单位体积的质量。
- **讲解**：【规律】密度 ρ = m/V，单位 kg/m³（常用 g/cm³）；**1 g/cm³ = 1000 kg/m³**；水的密度是 1.0×10³ kg/m³。【易错】密度是物质的**特性**，同种物质密度一般不变（不随质量、体积变）。
- **例子**：同体积的铁比木头重（铁密度大）；水结冰体积变大（冰的密度比水小）。
- **题**：
  1. 密度公式是？ → A. ρ = m/V ✓ / B. ρ = V/m / C. ρ = m·V / D. ρ = m+V
  2. 1 g/cm³ 等于多少 kg/m³？ → A. 1 / B. 100 / C. 1000 ✓ / D. 10000

### 6.3 测量物质的密度
- **定义**：用天平测质量、量筒测体积，算出密度 ρ = m/V。
- **讲解**：【实验】测固体密度（天平测 m，排水法测 V）；测液体密度（先测总质量、倒出后再测）。【易错】用量筒读数，视线要与液面**凹液面底部相平**。
- **例子**：测小石块的密度；测盐水的密度。
- **题**：
  1. 测量物质密度，需要测量的两个量是？ → A. 质量和体积 ✓ / B. 质量和温度 / C. 体积和温度 / D. 质量和时间
  2. 用量筒读数时，视线应与？ → A. 液面最高处相平 / B. 凹液面底部相平 ✓ / C. 任意位置 / D. 量筒外壁相平

### 6.4 密度与社会生活
- **定义**：用密度可以鉴别物质、解释生活现象。
- **讲解**：【规律】密度是鉴别物质的重要依据（ρ=m/V 算密度对表）；水反常膨胀——**4℃ 时水的密度最大**，水结冰体积变大。【易错】冬天水管冻裂是因为水结冰**体积变大**。
- **例子**：鉴别金块真假（测密度）；冬天水管冻裂。
- **题**：
  1. 冬天水管冻裂，是因为水结冰后？ → A. 质量变大 / B. 密度变大 / C. 体积变大 ✓ / D. 温度升高
  2. 鉴别物质的一种重要方法是测它的？ → A. 温度 / B. 密度 ✓ / C. 颜色 / D. 形状
