## 1. Goal

实现 Bible 第五章最后两款（本期立项范围）学习游戏：中译英、英译中。

目标：训练「中文 → 英文」与「英文 → 中文」两个方向的互译提取能力。
与极速选择的差异定位：极速选择考「限时压力下的熟练度」，
翻译双雄考「无时间压力下的方向准确性与连击稳定性」。

## 2. Scope

包含：

- 中译英（中文题干 → 4 个英文选项）
- 英译中（英文题干 → 4 个中文选项）
- 游戏结果、掌握/薄弱分析、复习集成

不包含：

- 拼写输入模式（中译英升级版，后续单独立项）
- 其余 Bible 游戏（拼单词/看图猜词/Boss 挑战——Owner 指示本期不做）

## 3. Entry Flow

游戏中心 → 中译英 或 英译中（两张独立卡片，共用同一引擎）→ 游戏结束 → 结果页面 → 加入复习

## 4. Game Mode V1

```
中译英：苹果 → A. apple  B. banana  C. grape  D. peach
英译中：apple → A. 苹果  B. 香蕉  C. 葡萄  D. 桃子
```

## 5. Game Rules

每局：默认 10 题（当前章节全部知识点；>10 随机抽 10，与全系列一致）。

来源：当前 Chapter 知识点（不要求已学习，挑战可直接进行）。

时间：**不设每题超时判错**（与极速选择的核心差异）；
记录每题用时仅作结果统计，不影响得分。

得分（统一评分体系）：

- 答对：+10 基础分 + 连击加成（+2 × 当前连击数）
- 答错：-2（总分下限 0）且连击清零
- 无速度奖励、无超时惩罚

## 6. Game State

READY → PLAYING → PAUSED → FINISHED → RESULT（与全系列一致）

## 7. Game Page

显示：

- 题干（中文释义 或 英文单词，随模式）
- 当前进度（第 x/10 题）、分数、Combo
- 4 个选项按钮

退出需要确认。切后台自动暂停（同全系列）。

## 8. Result Page

复用全系列统一结果页（memory-result）：

- 总分、正确数量、错误数量、用时、平均反应时间
- 分析：掌握知识 / 薄弱知识（答错）
- 按钮：再来一次 / 返回学习 / 加入复习

## 9. Data

- 复用 `memory_game_records`（`gameType: 'zh-en' | 'en-zh'`，零数据库变更）

## 10. Service

新增 TranslateService（一个服务承载两个方向）：

- startGame(userId, chapterId, direction)
- submitAnswer()
- finishGame()
- saveResult()

实现说明：选项生成完全复用 quizLogic——
中译英用 `buildWordChoiceQuestions`（英文选项），
英译中用 `buildChoiceQuestions`（中文选项）。

## 11. Repository

复用 MemoryGameRepository。

## 12. Learning Integration

与全系列完全一致：

- 答错知识点：生成或更新 review_records（明天复习）
- 答对知识点：masteryLevel + 1
- 触发时机：结果页「加入复习」按钮

## 13. Default Behavior

- 章节知识点 < 4：提示「本章节知识点不足，敬请期待」
- 网络失败：允许重试
- 退出：不保存本局

## 14. Acceptance Criteria

1. 游戏中心出现「中译英」「英译中」两张卡片
2. 中译英：中文题干 + 英文选项；英译中：英文题干 + 中文选项
3. 无每题超时判错（可从容作答），答错扣 2 分清连击
4. 实时显示分数、连击、进度
5. 生成游戏结果（gameType 分别为 zh-en / en-zh）
6. 答错知识可加入复习
7. 不影响学习闭环与其他游戏

## 15. Principle

翻译双雄是互译提取训练工具。
所有题目必须来自学习系统（knowledge 集合，单一来源）。
