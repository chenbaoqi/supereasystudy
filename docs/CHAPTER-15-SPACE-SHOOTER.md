## 1. Goal

实现第五款学习游戏：小蜜蜂（太空射击打字）。

玩法：中文单词方块从上方飘落，玩家用键盘输入对应的英文单词，
飞机发射子弹命中后击毁方块。融合「拼写训练 + 射击反应」，
是 Memory Challenge 系列中首款 Canvas 游戏。

## 2. Scope

包含：

- Canvas 2D 游戏引擎（方块飘落、飞机移动、子弹射击、爆炸动效）
- 键盘输入拼写（虚拟键盘 + 候选提示）
- 难度调节（方块数量、下落速度）
- 背景音乐 + 命中/失误音效
- 游戏结果、复习集成（与全系列一致）

不包含：

- 排行榜、多人对战、关卡系统（Boss 挑战留给 Bible 独立游戏）

## 3. Entry Flow

游戏中心 → 小蜜蜂 → 开始游戏 → 游戏结束 → 结果页面 → 加入复习

## 4. Game Mode V1

- 屏幕上方：中文释义方块（多块同时飘落，速度递增）
- 屏幕下方：虚拟键盘（QWERTY + 删除/空格），顶部显示已输入字母
- 屏幕中间：飞机（左右移动，自动发射 / 手动触发发射）

玩家看到中文方块（如「苹果」），用键盘敲入英文单词（apple），
输入匹配 → 飞机发射子弹击中「苹果」方块 → 爆炸消失 + 得分。

## 5. Game Rules

每局：不限时（敌人全部打完或飞机被撞 Game Over）。

来源：当前 Chapter 知识点（不要求已学习）。

难度（Q3）：

- 初级：同时 2 个方块，下落速度 1.5 秒/格
- 中级：同时 4 个方块，下落速度 1.0 秒/格
- 高级：同时 6 个方块，下落速度 0.6 秒/格

得分（统一评分体系）：

- 命中：+10 基础 + 连击加成（与全系列一致）
- 方块落地（漏掉）：-2 分（连击清零）
- 飞机被撞：Game Over，本局结束

## 6. Game State

READY → PLAYING → PAUSED → FINISHED → RESULT

## 7. Game Page

- 全屏 Canvas（方块飘落区）
- 底部虚拟键盘区（覆盖 Canvas 或悬浮 button 区）
- HUD：分数 / Combo / 难度

退出需确认。

## 8. Result Page

复用统一结果页：总分/命中数/漏掉数/用时。

## 9. Data

复用 `memory_game_records`（gameType='shooter'）。

## 10. Music & Effects（Q4）

- BGM：开源/CC0 游戏背景音乐（约 1-2 分钟 loop），云存储上传
- 命中音效：短促爆音
- 漏掉音效：警告音
- 爆炸动效：粒子扩散（Canvas 简单实现）

> 音效文件需准备：无版权素材；如暂无，V1 可先静音上线

## 11. Service

新增 SpaceShooterService：startGame / finishGame。

引擎：独立 `services/shooterEngine.ts`（纯逻辑可测：碰撞判定、矩形移动、输入匹配）。

## 12. Repository & Integration

复用 MemoryGameRepository。
复习集成同全系列（方块漏掉→薄弱，命中→mastery+1）。

## 13. Default

- 章节单词 < 4：提示「本章节知识点不足」
- 网络失败：允许重试（键盘游戏断网不影响）
- 退出不保存

## 14. Acceptance

1. 从游戏中心进入小蜜蜂
2. 方块飘落，键盘输入可射击
3. 命中+得分+爆炸动效；漏掉扣分
4. 难度可选，速度与数量变化
5. BGM 播放（如已配置音效）
6. 生成结果，加入复习
7. 不影响其他游戏

## 15. Principle

拼写是记忆的最深度提取——敲出单词比认出单词难得多。
先闭环（能玩），再逐轮升级音效/动画/难度曲线。
