# CHAPTER-14-TEXTBOOK-PREFERENCE

Version: 1.0 Status: Approved Priority: P0 Phase: Phase 2（体验优化）

> 2026-07-30 Owner 确认（Q1-Q4 全部按推荐）：
> 用户教材偏好一次设置长期复用，学习 tab 直达「我的教材」。

## 1. Goal

消除重复选择：用户设置一次 教材版本 + 册次 后，
进入学习 tab 直达当前教材章节列表，无需每次四连击。

## 2. Scope

包含：

- `users.preferences`（教材版本 + 册次 + 名称冗余）
- 偏好自动保存（册次被点开即视为当前偏好，无需额外按钮）
- 首页首次引导卡（未设置偏好时出现）
- 学习 tab 改造为「我的教材」（顶部当前教材横条 + 章节列表 + 切换入口）

不包含：

- 多教材并行收藏夹、按年级推荐教材、家长模式

## 3. Data

`users` 集合新增字段（RULES §7，依据本章）：

```ts
preferences: {
  textbookId: string; // 教材版本 id（如 人教版 PEP）
  textbookName: string; // 名称冗余（顶部横条展示免 join）
  semesterId: string; // 册次 id
  semesterName: string; // 名称冗余（如 三年级上册）
}
```

写入通道：云函数 `updateUserPreferences`（users 记录由 login 云函数以
管理端身份创建，客户端无写权限，必须云端收口；openid 由 getWXContext 注入不可伪造）。

## 4. Behavior

### 偏好保存（自动）

用户在任何入口点开某个册次 → 自动保存为当前偏好
（「最近使用的册次即偏好」，无需确认按钮；再点别的册次自然覆盖）。

### 首页引导卡（未设置偏好时）

首页顶部（Banner 下）出现一次性的：
「📚 选你的教材和册次，下次直接学」→ 点击进学科选择流。
设置后永久消失（直到偏好被清空）。

### 学习 tab「我的教材」

- 已设偏好：顶部横条 `教材名 · 册次名 ▾`（点击回选择流切换）+
  当前册次章节列表（状态/测试/挑战入口与章节页一致）
- 未设偏好：引导卡「先选择你的教材」→ 学科页

### 章节页重构

章节列表数据装配抽取为 `chapterService.buildChapterItems(userId, semesterId)`，
章节页与学习 tab 共用（DRY）。

## 5. Acceptance

1. 新用户首页出现引导卡，选完教材册次后消失
2. 学习 tab 直接显示当前册次章节列表（含状态/测试/挑战入口）
3. 顶部横条可切回选择流更换教材
4. 再点其他册次后，学习 tab 自动变为新册次
5. 原四连击选择流保留可用

## 6. Principle

偏好跟着使用走，不给用户加操作负担；
学习 tab 是教材的家，不是选择器的重复。

## 修订（2026-07-31，Owner）：教材选择模型定稿

- **命名**：功能统称「教材选择」（我的页入口、首页引导卡同名）
- **首次强制**：首次点学科必须完成「版本 → 年级 → 学期」三步选择，之后默认
- **一个学科一种组合**：一个学科只能选一种 版本+年级+学期；选择到学期即结束
- **选完回原点**：点完学期 → 保存偏好 → 回到学习页，顶部标注「版本｜年级｜学期」
- **年级拆分**：数据层册次不变（三年级上册），展示层派生年级步（版本 → 年级 → 学期），
  浏览路径：学科 → 学习路径 → 教材(版本) → 年级 → 学期 → 学习页
- **乱码修复**：教材名路由编码未解码入库的问题已修复（重新选择一次即刷新正常中文）
- **语法扁平化**：点语法直达专题章节（按学段匹配专题包），不经过专题包/全册两层
