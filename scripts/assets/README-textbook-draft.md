# 教材骨架说明（方案 A：AI 生成 + 人工校对）

## ⚠️ 数据性质（使用前必读）

`textbook-draft-pep-7a.csv`（批次 1：人教版 PEP 2024 新版七年级上册
Starter Unit 1–3 + Unit 1–2，共 86 词）为 **AI 生成的校对骨架**：

- **单元结构**：贴近人教版 PEP 2024 新版七上（AI 训练知识，**未经实体教材核实**）
- **词汇**：按单元主题编写的常见初中词汇（**非教材原词表**）
- **例句/翻译**：AI 为练习编写的简单句（非教材原句，无版权问题）
- **音标**：常见词典标注（DJ 音标）

**红线：本文件是「待校对草稿」，不是真实教材数据。**
必须由教师/您对照实体教材完成校对（增、删、改）后，方可作为正式数据导入。

## 校对与导入流程

1. 用 Excel/WPS 打开 CSV 校对（可直接增删行、改词）
2. 校对完成告诉我 → 我执行 `node scripts/convert_textbook.mjs <csv路径>`
3. 部署并运行 `resetAndImport`（清库 A + 导入）
4. 批次 2（Unit 3–7）待批次 1 验收后生成

## 新增版本/年级

告诉我「版本 + 年级/册次」（如：外研版 七年级上册），我按同流程生成骨架。
