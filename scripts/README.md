# scripts/ — 工程脚本

## 职责

存放开发与运维辅助脚本（Node 脚本，不进小程序运行时）。

## 规划（按依赖就绪顺序）

| 脚本              | 作用                                                           | 前置条件                |
| ----------------- | -------------------------------------------------------------- | ----------------------- |
| `init-database`   | 按 `cloud/database/collections.json` 批量创建/校验云数据库集合 | 云环境 ID（pending #1） |
| `check-docs-sync` | CI 中校验 docs 与目录结构基线一致                              | 无                      |

## 规则

- 脚本必须可用 `node scripts/xxx.mjs` 直接运行，不依赖全局安装
- 脚本只做工程自动化，**禁止包含产品业务逻辑**
