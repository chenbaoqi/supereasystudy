# pages/ — 页面层（薄）

## 职责

只负责：展示、交互、动画。

## 规则（宪章「页面原则」）

| 禁止                           | 必须                      |
| ------------------------------ | ------------------------- |
| 业务计算                       | 调用 `services/` 获取数据 |
| 直接访问数据库 / 调用 wx.cloud | 通过 Service 间接获取     |
| 复杂逻辑（超过 50 行的函数）   | 下沉到 Service 或抽组件   |
| 单文件超过 300 行              | 立即拆分                  |
